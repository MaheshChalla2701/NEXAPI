# data/ — SYNTHETIC dataset

> **SYNTHETIC DATA.** Every file in this folder is generated by `python3 -m datagen.generate` for an
> analytics exercise. No real company, customer or payment is represented. Any finding computed from
> these files is a finding about the synthetic scenario only.

This README describes the files the way an analytics team would hand them over. How and why the
values were generated is documented separately in `ASSUMPTIONS.md` (generated from `datagen/config.py`).
`MANIFEST.json` lists the seed, the one calibrated parameter, row counts and a SHA-256 checksum per file.

All timestamps are UTC (ISO 8601, `Z` suffix). Amounts are in the currency named on the row.

| File | Grain | Key | What it holds |
|---|---|---|---|
| `workspaces.parquet` | one row per workspace | `workspace_id` | Country, company size, sign-up channel, hashed owner e-mail, and a **snapshot as of the extract date** of current plan and status |
| `events/YYYY-MM-DD.csv.gz` | one row per product event, one file per day | `event_id` | Product events for workspaces created on/after 2026-02-01 |
| `subscriptions.csv` | one row per subscription | `subscription_id` | Plan, billing interval, currency, list price at start, discount, start / cancellation / end, cancel reason, status at extract |
| `payments.csv` | one row per payment attempt or refund | `payment_id` (expected) | Charges (with retries), refunds, failures, billing period covered |
| `experiment.csv` | one row per assignment log entry | (`experiment_id`, `workspace_id`) expected | Onboarding test: which workspaces were assigned to `control` or `new_onboarding` |
| `referrals.csv` | one row per referral record | `referral_id` | Partner, referral code, referred workspace, time, payout amount and status |
| `support_tickets.csv` | one row per ticket | `ticket_id` | Workspace, time, channel, subject and free-text body (no category column) |
| `fx_rates.csv` | one row per month and currency | (`month`, `currency`) | USD per unit of currency, monthly average |

## Columns

**workspaces.parquet** — `workspace_id`, `created_at` (timestamp, UTC), `country` (ISO-2), `company_size`
(`1-5`, `6-20`, `21-50`), `signup_channel` (`organic_search`, `direct`, `paid_ads`, `content`,
`app_marketplace`, `partner_referral`), `owner_email_hash`, `current_plan` (`free`, `starter_monthly`,
`team_annual`, …), `current_status` (`free`, `paying`, `past_due`, `churned`).
Contains every workspace created since 2025-01-01, plus older workspaces that were paying customers on
2025-01-01.

**events/** — `event_id`, `workspace_id`, `user_id`, `event_type`, `event_ts`, `properties`
(`key=value;…`). Event types: `workspace_created`, `onboarding_step_completed`,
`onboarding_email_clicked`, `project_created`, `member_invited`, `login`, `task_created`,
`task_completed`, `comment_added`, `file_uploaded`, `partner_sync`, `checkout_completed`.
Files run from 2026-02-01 to 2026-10-04 (extract taken 2026-10-05).

**subscriptions.csv** — `subscription_id`, `workspace_id`, `plan` (`starter`, `team`),
`billing_interval` (`monthly`, `annual`), `currency` (`USD`, `EUR`, `GBP`), `list_price` (per billing
period at start), `discount_pct`, `started_at`, `cancelled_at`, `ended_at`, `cancel_reason`, `status`.

**payments.csv** — `payment_id`, `invoice_id`, `subscription_id`, `workspace_id`, `type` (`charge`,
`refund`), `status` (`succeeded`, `failed`), `attempt` (1–3; retries share the invoice), `amount`,
`currency`, `created_at`, `period_start`, `period_end`, `failure_code`, `refund_of` (payment refunded).
History starts 2025-01-01.

**experiment.csv** — `experiment_id`, `workspace_id`, `country`, `variant`, `assigned_at`.

**referrals.csv** — `referral_id`, `partner_id`, `referral_code`, `referred_workspace_id`,
`referred_at`, `payout_usd`, `payout_status` (`paid`, `pending`, `rejected`), `payout_paid_at`.

**support_tickets.csv** — `ticket_id`, `workspace_id`, `created_at`, `channel`, `subject`, `body`.

## How the files join

```
workspaces ─┬─< subscriptions ─< payments          (workspace_id, subscription_id)
            ├─< events                              (workspace_id)
            ├─< experiment                          (workspace_id)
            ├─< referrals                           (workspace_id = referred_workspace_id)
            └─< support_tickets                     (workspace_id)
payments >── fx_rates                               (currency, month of created_at)
```

## Dashboards

`dashboards/*.sql` are the queries behind the company's current dashboards. They run against
`var/warehouse.sqlite`, built by `python3 -m scripts.build_warehouse`. `python3 -m scripts.run_dashboards`
prints their output.
